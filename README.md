# Bewerbungsmappe de Paola

App para preparar el CV alemán de Paola y seguir ofertas de hostelería con alojamiento en Alemania.

- `index.html`: la web (GitHub Pages). Solo entran los correos autorizados en Supabase.
- `supabase/functions/ai/`: función del servidor. Busca en la Arbeitsagentur, puntúa con Claude, escribe cartas y manda avisos por correo.

Los datos y las claves viven en Supabase, no en este repositorio.
